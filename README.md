# disloc_3dRender
3D renderings of dislocation core structures

Run `screwDisloc/main.py` after installing `screwDisloc/requirements.txt` to
export the imported object as `config.glb` and generate a looping
`config.gif` showing a 3D camera rotation around it. The generated GIF is
shown in `screwDisloc/index.html` below the interactive model viewer.
